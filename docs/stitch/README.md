# Google Stitch design evidence

The UI was first designed in **Google Stitch** (project "Restoration Studio Web App",
https://stitch.withgoogle.com/projects/15405053876497811916) from this prompt, and the React/Tailwind frontend
in `frontend/` was then implemented from that design (palette #6366F1 / cyan / teal, Space Grotesk + Geist fonts,
left navigation with four workspaces, control card + image-panel grid + stats card layout).

Prompt given to Stitch (Web mode): *Design a responsive desktop web app named 'Restoration Studio' for an AI
image-restoration and face-to-sketch demo. Dark, clean, modern design with a left sidebar navigation and a top bar
showing backend health status. Four workspaces ... (Universal Restoration, Hard-Routed Restoration, Soft
Mixture-of-Experts, Face-to-Sketch Generator) ...* (full prompt in the technical report).

Files: `stitch_canvas_overview.jpg` (whole canvas with design system and screens), `screen*.png` (individual screens).
